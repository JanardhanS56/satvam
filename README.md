# Satvam — From India's Roots to Your Roots

Ayurvedic herbal hair oil e-commerce showcase. 3D Web Design Competition entry.

- **Stack:** Vite + React + Tailwind + GSAP + Lenis + Zustand + react-router-dom + Lucide
- **Backend:** None (pure frontend). Groq API called client-side via VITE_GROQ_API_KEY.
- **Deploy:** Vercel (single-page-app rewrite).
- **Data:** `src/data/products.json` (20 products, 5 marked `hero`).

## Quick start
```bash
npm install
cp .env.example .env       # add VITE_GROQ_API_KEY
npm run dev
```

LIVE AT: https://satvam.vercel.app
